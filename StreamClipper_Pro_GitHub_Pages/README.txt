STREAMCLIPPER PRO — GitHub Pages Website

1. BEFORE PUBLISHING: Open terms.html, privacy.html, contact.html in a text editor; fill EVERY [BRACKETED FIELD], check actual data flows / AI services / business details. Delete the warning blocks in each legal page when reviewed. The texts are drafts and are NOT a guarantee of legal compliance.
2. Go to https://github.com/new and create a PUBLIC repository named streamclipper-site.
3. Upload index.html, terms.html, privacy.html, contact.html, style.css and .nojekyll directly into the repository root. Do not upload this ZIP itself.
4. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
5. Site URLs will usually be:
   https://YOUR-GITHUB-USERNAME.github.io/streamclipper-site/
   https://YOUR-GITHUB-USERNAME.github.io/streamclipper-site/terms.html
   https://YOUR-GITHUB-USERNAME.github.io/streamclipper-site/privacy.html
6. To verify with TikTok: TikTok Developer Portal > PRODUCTION > URL properties > Verify properties > URL prefix. Enter https://YOUR-GITHUB-USERNAME.github.io/streamclipper-site/ (trailing slash). Download TikTok signature file and upload it into repository at its required path (follow TikTok's exact instructions; do not rename or edit signature). TikTok may require a specific signature-file path, so check the resulting published URL before clicking Verify.
7. Never place TikTok Client Secret or access tokens into GitHub files.
8. GitHub Pages is public. Make sure the controller name/address/contacts are complete and lawful, and review platform requirements and GDPR with a qualified adviser if needed.

Note: GitHub Pages URL prefix verification is more suitable than trying to prove ownership of github.io domain. Support may depend on TikTok's validation rules.
